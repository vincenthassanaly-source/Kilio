# Rapports

Journaux datés d'audits, de décisions et de chantiers (`AAAA-MM-JJ-sujet.md`). Ce sont des **traces historiques**, pas de la documentation vivante :

- Le code fait foi. Un rapport peut décrire un état qui a changé depuis.
- La source de vérité produit est [`PRODUCT.md`](../PRODUCT.md), le design system est dans [`DESIGN.md`](../DESIGN.md).
- Ne pas mettre à jour un ancien rapport : en écrire un nouveau, daté, qui le remplace si besoin.
